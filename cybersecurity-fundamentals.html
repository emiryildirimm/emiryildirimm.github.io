Cybersecurity Fundamentals & Concepts

March 12, 2026 Fundamentals ~10 min read

A compilation of my exact notes on basic cybersecurity roles, the OSI model, networking fundamentals, and core concepts like the CIA triad and cryptography.

Cybersecurity Roles

  • Security Analysts: Security Analysts are responsible for analyzing the security of companies.
  • Security Engineers: Security Engineers develop and implement security solutions using threats.
  • Incident Responders: Incident responders responds to attacks MTTD, MTTA and MTTR - the meantime to detect.
  • Digital Forensics Examiners: Digital Forensics Examiners work like a detective.
  • Malware Analysts: malware analyst's work involves analysing suspicious programs, discovering what they do and writing reports about their findings.
  • Penetration Testers: Penetration Testers try to find vulnerabilities on a system.
  • Red Teamers: Red Teamers are similar with Penetration testers but they fully act like a Hacker.

Networking Hardware & Topologies

MAC Addresses: a4:c3:f0:85:ac:2d -> the first six characters the company that made the "network interface" and the last six is a "unique number".

Network Topologies

  • Star Topology: via a central networking device such as switch or hub and the other devices are individually connected.
  • Bus Topology: There is a backbone cable if this cable break all the network is gonna be break but this topology is more cost efficient. This topology looks like a leaf on a tree.
  • Ring Topology: Devices such as computers are connected directly to each other to form a loop. A ring topology works by sending data across the loop until it reaches the destined device.

Networking Devices

  • What is a Switch: Switches are dedicated devices within a network that are designed to aggregate multiple other devices such as computers, printers, or any other networking-capable device using ethernet. Switches can track of what device is connected to the which port. And with this way it is very easy to send the data to responsible device.
  • Router: Router's job is connect networks and pass data between them.

Core Protocols

  • ICMP: a network-layer protocol used by devices like routers to diagnose communication issues and report errors. ping sends 6 ICMP packets. ping -c 4 says send 4 ICMP packet.
  • ARP: is responsible for finding the MAC address related to a specific IP address. ARP Request -> a message is broadcasted on the network to other devices asking "What is the mac address that owns this IP address". ARP Reply -> they will only respond if they own that IP address and will send an ARP reply with it's MAC address and ARP keeps it in the "ARP cache".
  • DHCP(Dynamic Host Configuration Protocol): When a device connects to a network, if it has not already been manually assigned an IP address it sends out a request "DHCP" to see if any DHCP servers are on the network. and then "DHCP Offer" -> "DHCP Request" -> "DHCP ACK".

OSI -> (Open Systems Interconnection Model)

encapsulation -> pieces of information get added to data.

  • Physical -> Devices use electrical signals to transfer data between each other in a binary numbering system -> Ethernet Cables.
  • Data Link -> NIC => Every device has a Network Interface Card which comes with a unique "MAC" address.
  • Network -> OSPF(Open Shortest Path First) and RIP(Routing Information Protocol) it find the optimal path that data should take to reach a device -> IP.
  • Transport layer -> TCP AND UDP.
    • TCP(Transmission Control Protocol) -> this protocol is designed with reliability and guarantee in mind. This protocol reserves a constant connection between the two devices for the amount of time. TCP also has error checking function. TCP is significantly slower than UDP.
    • UDP -> User Datagram Protocol -> it sends the data whether it gets receiver or not. ARP and DHCP use UDP and also video streaming uses UDP.
  • Session Layer -> The session layer is also responsible for closing the connection if it hasn't been used in a while or if its is lost. Session can contain "checkpoints" where if the data is lost, only the newest pieces of data are required to be sent saving bandwidth.
  • Presentation -> is a translator for data to and from the application layer. data encryption occur at this layer.
  • Application -> GUI.

Packet vs Frame

  • Packet -> is a piece of data from Layer 3 -> IP Header and payload. Packet is a letter.
  • Frame -> is used at Layer 2 adds additional information such as MAC addresses. Frame is an envelope.

this process is called encapsulation.

Packet Headers

  • Time to live -> TTL -> a numerical value in an IP packet that acts as an expiration limit. It ensures data doesn't circulate endlessly across a network.
  • Checksum -> If any data is changed, this value be different from what was expected and therefore corrupt.
  • Source Address -> The IP address of the device that the packet is being sent from so that data knows where to return.
  • Destination Address -> The device's IP address the packet is being sent to so that data knows where to travel next.

if a data has IP addressing information -> it is a Packet.

TCP packets contain various sections

  • Source Port -> sender port this value is chosen randomly.
  • Destination Port -> receiver port this value is not chosen at random.
  • Source IP -> this is the ip address of the device that is sending the packet.
  • Destination -> This is the IP address of the device that the packet is destined for.
  • Sequence Number -> the first piece of data transmitted is given a random number.
  • Acknowledgement -> sequence number + 1.

FLAGS ->

  • SYN
  • SYN ACK
  • ACK
  • DATA
  • FIN -> Properly close the connection.
  • RST -> This packet abruptly end all communication.
  • ISN -> Initial Sequence Number -> Both computers must agree on the same number sequence for data to be sent in the correct order.

Core Security Principles & OS

CIA Triad

  • Confidentiality -> You want to ensure that secret and private files and information are only available to intended person.
  • Integrity -> Everything need to be as planned.
  • Availability -> You want your laptop or smartphone to be available all the time.
  • AIX -> Unix based operating system.
  • Solaris is a operating system as well.
  • node is start to a javascript application.
  • The caesar Cipher -> A shifts forward 3 spots to become D.
  • symmetric encryption -> the same key encrypts and decrypts the lock.
  • asymmetric encryption -> there are two different keys.
  • Exploit: A technique or method used to take advantage of a vulnerability to achieve a specific outcome, such as accessing restricted functionality or data.
